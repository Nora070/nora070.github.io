Abstract:¶

This project will investigate equity return predictions using several sources of financial data. Three sources we are using include company fundamentals from S&P Capital IQ, technical indicators from Bloomberg Terminals, and macroeconomic data from the Federal Reserve Economic Data.

Combining these sources into one dataset, we hope to investigate which indicator may be the most predictive, which variables hurt equity performance, and if the combination of disparate sources can contribute to a more informed investment strategy.

Data Description:¶

The first data set we will be investigating is from the St. Louis Federal Reserve Bank. This data set contains four attributes;

Federal Funds Rate: The rate depository institutions (mainly banks) lend reserve balances to other depository institutions overnight, set by the Federal Open Market Committee (FOMC).

Consumer Price Index (CPI) inflation: measures the average change over time in prices paid by urban consumers for a representative "basket" of goods and services. It is a key economic indicator used to gauge the purchasing power of currency and cost-of-living changes.

10-year minus 2-year treasury yield spread: Compares the return rates of long and short term investments, such as bonds. Can serve as an indicator for consumer confidence and serve as a barometer for the economy.

Unemployment rate: The percentage of the laborforce that doesn't have a job.

Source: https://fred.stlouisfed.org/

Data pulled using an API key

This data set has one observation for the first of each month from 2005 to 2025.

Although this data set does not contain our target variable of equity return, it can help represent and quantify critical, but more abstract, factors such as consumer confidence.
